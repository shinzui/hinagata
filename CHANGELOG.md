# Changelog

## 0.1.0.0 - 2026-10-18

### New Features

- First public release of hinagata-core, hinagata-postgres, and hinagata-cli at a shared version.
- Compile deterministic SQL and CSV fixture plans into verified, content-addressed local bundles, with typed configuration and explicit PostgreSQL targets.
- Load fixtures atomically through private native PostgreSQL sessions with streaming COPY.
- Build and reuse sealed baselines; lease isolated clones with bounded concurrency, per-clone preparation, retention, ownership-checked cleanup, crash recovery, and lifecycle timing reports.
- Provide fixture planning, loading, and validation commands; baseline preparation; lease acquisition, command handoff, release, inspection, and cleanup.
- Derive migration and verification hook revisions from declared executable, file, and value inputs.

### Bug Fixes

- Reject transaction-control statements across PostgreSQL whitespace and honor explicit connection targets over ambient host addresses.
- Propagate cancellation through native commands, child processes, callbacks, and resource cleanup.
- Preserve PostgreSQL list and scalar role settings and invalidate baselines created with the earlier setting semantics.
- Retain structured fixture failure context through baseline, lease, manager, and CLI diagnostics, with separate rollback and release errors.

### Other Changes

- Include user guides, integration examples, crash-recovery coverage, and reference-machine performance evidence.
- Add package changelogs, repository metadata, required autogenerated-module declarations, and PVP bounds for internal dependencies.
- Run PostgreSQL integration tests on disposable clusters in the unpacked-source and full check gates, and include CLI PostgreSQL lifecycle tests in the full gate.
