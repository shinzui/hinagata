# Changelog

## 0.1.0.0 - 2026-10-18

### New Features

- Load verified SQL and streaming CSV fixtures in one transaction on an exclusive native PostgreSQL session.
- Build, verify, seal, reuse, compare, and retire baseline generations through a versioned maintenance catalog.
- Lease isolated clones with preparation hooks, scenario loading, classified callback outcomes, detached or retained leases, and lifecycle timing reports.
- Bound manager admission and named clone collections; inspect, preview, and apply ownership-checked cleanup with crash recovery.
- Upgrade owned maintenance catalogs from format 1 to format 2.

### Bug Fixes

- Enforce acquisition deadlines, cancel native commands, close interrupted resources, and interrupt callbacks after lease ownership is lost.
- Preserve PostgreSQL list and scalar role-setting semantics and invalidate baselines created with the earlier encoding.
- Preserve structured fixture context through baseline and lease errors, with independent rollback and release diagnostics.
- Recover interrupted baseline publication and clone release while refusing cleanup when ownership is ambiguous.

### Other Changes

- Include a test adapter example, concurrency benchmarks, crash-boundary tests, and packaged SQL catalog migrations.
- Add package changelog, repository metadata, required autogenerated-module declarations, and internal PVP dependency bounds.
