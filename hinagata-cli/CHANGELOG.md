# Changelog

## 0.1.0.0 - 2026-10-18

### New Features

- Provide offline fixture planning, direct loading into an explicit target database, and fixture validation.
- Prepare reusable baselines; acquire, release, inspect, and clean leases; run commands within a scoped database lease.
- Load layered YAML, environment, and command-line configuration with schema descriptions, explanations, validation, shell completions, and JSON output.
- Supervise per-clone preparation commands and derive migration and verification revisions from declared content inputs.
- Pass explicit PostgreSQL connection variables and run and lease identifiers to service and test commands.

### Bug Fixes

- Honor explicit endpoints over ambient host addresses and prevent application handoff after failed preparation.
- Stop supervised commands on cancellation and preserve leases when child-process cleanup is uncertain.
- Report structured fixture failures across lifecycle commands without exposing secret values.

### Other Changes

- Include package changelog, description, repository metadata, required autogenerated-module declaration, and internal PVP dependency bounds.
