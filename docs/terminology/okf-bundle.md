# OKF bundle

A directory of Markdown concepts governed by an Open Knowledge Format contract.

Hinagata has separate OKF bundles for user documentation, task guides, and terminology.
Their indexes declare OKF v0.2.
For example, each term has a stable `TERM-N` handle within the terminology bundle.
This documentation structure is separate from the fixture bundles that hold SQL and CSV inputs.
See [Maintain documentation](../guides/maintain-documentation.md).
